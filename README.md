# PDF Master · versión de pruebas

Descarga y avisos de fallos de la versión de pruebas de PDF Master para Windows.

- Web: https://axeldoqui.github.io/pdf-master-pruebas/
- Instalador: pestaña **Releases**.
- ¿Algo falla? Abre un aviso con el formulario de **Issues**.

Este repositorio no contiene el código de la app, solo la página de descarga y los instaladores.
